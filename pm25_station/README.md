# 🌫️ ระบบติดตามค่าฝุ่น PM2.5 ด้วย Raspberry Pi 5

สอนเขียนโค้ดตั้งแต่ศูนย์ — เข้าใจง่าย ทำตามได้ทีละขั้น 🙂

ระบบนี้จะ:
1. อ่านค่าฝุ่น **PM2.5** จริง จากเซนเซอร์ **PMS3003**
2. อ่าน **อุณหภูมิ / ความชื้น** จากเซนเซอร์ **DHT22**
3. ถ่ายภาพท้องฟ้าจาก **กล้อง webcam** แล้วให้ **AI ดูภาพบอกระดับฝุ่นควัน**
   (🟢 ไม่มีฝุ่นควัน / 🟡 มีฝุ่นควันปานกลาง / 🔴 ฝุ่นควันหนักมาก)
4. แสดงผลทั้งหมดบน **เว็บ Dashboard** แบบเรียลไทม์

---

## 📚 บทที่ 0 — ทำความเข้าใจก่อนเริ่ม (สำคัญมาก!)

บน Raspberry Pi 5 มี **2 หน้าต่างที่ต้องแยกให้ออก**:

| หน้าต่าง | หน้าตา | เอาไว้ทำอะไร |
|----------|--------|--------------|
| **Thonny** | พื้นที่**สีขาว** มีปุ่ม ▶️ สีเขียว "Run" | **เขียนโค้ด Python** แล้วกดรัน |
| **Terminal** | หน้าจอ**สีดำ** พิมพ์คำสั่ง | ติดตั้งของ / เปิดการตั้งค่า (ใช้แค่ตอนติดตั้ง) |

> 💡 **การเขียนโค้ด = พิมพ์ในพื้นที่สีขาวของ Thonny**
> พอกดปุ่ม ▶️ Run สีเขียว มันจะ **ขอให้ตั้งชื่อไฟล์ครั้งเดียว** แล้วรันให้เลย
> ครั้งต่อไปแค่กด Run มันเซฟให้เอง — **ไม่ต้องแตะหน้าจอสีดำเลยก็ได้**

### ลองพิสูจน์ 30 วินาที
เปิด Thonny → พิมพ์ในพื้นที่ขาว:
```python
print("สวัสดี Raspberry Pi 5")
```
กด ▶️ Run → ตั้งชื่อ `test.py` → ข้างล่างจะขึ้นข้อความ = **คุณเขียนโค้ดเป็นแล้ว!** 🎉

## 🔌 บทที่ 1 — ต่อสายอุปกรณ์

```
PMS3003 (เซนเซอร์ฝุ่น)
    VCC  -> 5V          (ขา 2)
    GND  -> GND         (ขา 6)
    TX   -> GPIO15/RXD  (ขา 10)
    RX   -> GPIO14/TXD  (ขา 8)

DHT22 (อุณหภูมิ/ความชื้น)
    VCC  -> 3.3V        (ขา 1)
    DATA -> GPIO4       (ขา 7)   *ต่อ R 10kΩ ระหว่าง VCC กับ DATA
    GND  -> GND         (ขา 9)

กล้อง C270 -> เสียบพอร์ต USB ได้เลย
```

## ⚙️ บทที่ 2 — ตั้งค่า Pi ครั้งเดียว (ใช้หน้าจอสีดำ)

เปิด **Terminal** (สีดำ) แล้วพิมพ์ทีละบรรทัด:

```bash
# 1) เปิด UART ให้ PMS3003 คุยกับ Pi ได้
sudo raspi-config
#   -> Interface Options -> Serial Port
#   -> "login shell over serial?"  ตอบ No
#   -> "serial port hardware enabled?"  ตอบ Yes
#   แล้ว reboot

# 2) ติดตั้งไลบรารีที่ต้องใช้
sudo apt install -y libgpiod2
pip install -r requirements.txt
```

> ถ้าแค่อยากลองระบบก่อน (ยังไม่ต่อเซนเซอร์) ข้ามข้อ 1 ได้ ติดตั้งแค่ `pip install flask`

---

## ▶️ บทที่ 3 — ลองรันแบบจำลองก่อน (ยังไม่ต้องมีเซนเซอร์)

ในไฟล์ `config.py` ให้ตั้งค่า:
```python
USE_MOCK = True     # โหมดจำลอง สร้างข้อมูลปลอมไว้ทดสอบ
```

จากนั้นเปิดไฟล์ **`app.py`** ใน Thonny แล้วกด ▶️ **Run**

เปิดเบราว์เซอร์ไปที่ 👉 **http://localhost:8000**
จะเห็น Dashboard มีตัวเลขขยับ + กราฟ + ระดับฝุ่นควัน = ระบบพร้อมแล้ว!

ดูจากมือถือในวง Wi-Fi เดียวกันก็ได้:
```bash
hostname -I        # หาไอพีของ Pi เช่น 192.168.1.50
```
แล้วเปิด `http://192.168.1.50:8000` บนมือถือ

---

## 🌡️ บทที่ 4 — เปลี่ยนไปใช้เซนเซอร์จริง

พอต่ออุปกรณ์ครบและทำบทที่ 2 แล้ว แค่แก้ `config.py`:
```python
USE_MOCK = False    # อ่านจากเซนเซอร์จริง
```
แล้วกด ▶️ Run ที่ `app.py` อีกครั้ง — เท่านี้ก็ใช้ค่าจริงแล้ว

### อยากทดสอบเซนเซอร์ทีละตัว?
เปิดไฟล์แล้วกด Run ได้เลย (จะพิมพ์ค่าออกมาให้ดู):
| ไฟล์ | ทดสอบ |
|------|-------|
| `sensors/pms3003.py` | อ่านค่าฝุ่น |
| `sensors/dht22.py` | อ่านอุณหภูมิ/ความชื้น |
| `camera.py` | ถ่ายภาพ 1 รูป |

## ❓ แก้ปัญหาที่เจอบ่อย

| อาการ | วิธีแก้ |
|-------|---------|
| อ่าน PMS3003 ไม่ได้ | ยังไม่เปิด UART (บทที่ 2 ข้อ 1) หรือสลับสาย TX/RX |
| อ่าน DHT22 ไม่ได้ | ลอง Run ซ้ำ (DHT22 พลาดบ่อยเป็นปกติ) เช็ค R 10kΩ |
| กล้องถ่ายไม่ได้ | เช็คว่าเสียบ USB แล้ว ลองเปลี่ยน `CAMERA_INDEX` เป็น 1 |
| เปิดเว็บไม่ได้ | ต้องกด Run `app.py` ค้างไว้ (อย่าปิด) แล้วค่อยเปิดเบราว์เซอร์ |
| ระดับฝุ่นควันไม่ตรง | ปรับเกณฑ์ `SAT_CLEAR` / `SAT_MODERATE` ใน `haze.py` |
```
