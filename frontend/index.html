ℹ️ เกี่ยวกับระบบ (About)

ระบบติดตามและประเมินค่าฝุ่น PM2.5 ด้วย AI

ระบบนี้ใช้กล้อง Webcam ถ่ายภาพท้องฟ้า แล้วใช้โมเดล AI ประเมินค่าฝุ่น PM2.5 จากลักษณะหมอกควันในภาพ โดยเทียบเคียงกับค่าจริงจากเซนเซอร์ PMS5003

  • อุปกรณ์: Raspberry Pi 5, Logitech C270 Webcam, PMS5003 (เซนเซอร์ฝุ่น), DHT22 (อุณหภูมิ/ความชื้น), Micro SD Card, อุปกรณ์จ่ายไฟ USB-C PD
  • โมเดล AI: สกัดฟีเจอร์หมอกควันจากภาพ + Gradient Boosting Regression
  • หลังบ้าน: Python Flask + SQLite
  • หน้าบ้าน: HTML / CSS / JavaScript (Dashboard)
